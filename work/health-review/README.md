# ヘルス画面の確認

2026-10-13、iPhone 17 Pro / iOS 26.1、日本語。画面は専用シミュレーターデモの記録を使用しています。

- 直近1週間の平均を残し、各カードから週・月・半年・年の履歴へ移動。
- 睡眠は起床日と現地時刻を軸に表示。覚醒・レム・コア・深い睡眠・不明を色分けし、日詳細で就寝・起床、段階別時間と割合を確認。
- 健康状態は歩数・睡眠・気分・体調を共通の日付軸で比較。未記録の評価は補完しません。
- Fitnessは日別活動サマリーの実値・実目標を使用。追加の読み取り権限は「ヘルスケア連携を確認」から取得。

睡眠時間は昼寝を含む実睡眠の合計です。覚醒・ベッド時間・未測定の隙間を除き、重複区間を一度だけ数えます。就寝・起床時刻は最長の主睡眠です。夏時間の終了日は変更前後を左右の帯で表示します。
