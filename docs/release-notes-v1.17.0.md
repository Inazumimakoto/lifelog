## 対象範囲と運用上の注意

- 新しい繰り返し予定に対する個別編集・休み・振替・通知などの調整は「繰り返し予定」の新機能へまとめ、改善として重複掲載していない。
- 写真背景、カテゴリ管理、買い物リスト、習慣、振り返りマップは比較タグ時点で存在するため、今回の変更は改善として扱う。
- ChatGPT・Cloudflare連携と買い物クラウド同期は比較タグ後に追加・撤去されており、最終版で提供されないため案内しない。日記のAI採点・分析・書き出しは比較タグ時点で存在するため、終了を案内する。
- 課金は `MonetizationPolicy.isBillingTemporarilyDisabled = true` のまま。料金プランや新たな有料制限は案内しない。
- SwiftDataには繰り返し予定・例外・URL・日別フィットネス目標などの保存項目が追加されている。買い物の購入済み商品は起動時の整理対象となり、数量はメモに引き継がれる。実機での既存データ更新は今回未検証。
- AIや外部連携の旧版・サーバー側の運用は [AI分析の終了](ai-analysis-retirement.md) と [ChatGPT・Cloudflare連携の終了](chatgpt-cloudflare-retirement.md) を参照。本作業ではサーバー停止・本番Firestore変更を行わない。
- App Storeへのアップロード・審査提出・配信、GitHub Release作成はこの作業に含まない。
